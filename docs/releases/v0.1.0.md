# v0.1.0 · 首个 macOS 实验性版本

发布日期：2026-11-26（Asia/Shanghai）。这是个人 AI 工作台的首个源码预发布版本，适合本机单用户试用和验证，不代表无人值守或生产可用性承诺。

## 当前支持范围

仅支持 macOS。实际构建与隔离验证环境：macOS 15.3.1、Apple Silicon arm64、Node.js 24.18.0、npm 11.16.0。Intel Mac、其他 macOS 版本没有本次验收证据；Windows 和 Linux 不在支持范围。独立验证依赖 `/usr/bin/sandbox-exec` 和 `/bin/zsh`，后台常驻依赖 LaunchAgent。

交付物是源码、源码压缩包及 SHA-256 校验清单，没有 DMG/PKG、内置 Node、Codex 二进制、应用签名或公证。依赖安装需要访问 npm；Codex 和消息渠道需要各自的账户、网络与授权。仓库尚未声明开源许可证。

## 首版包含什么

- 本地 Web 工作台：总览、任务搜索筛选和分页、任务结果与证据审阅、项目与知识管理、系统设置、弹窗未保存提醒和窄屏导航。
- 项目注册及 Codex 项目发现；导入需用户确认，支持多仓库、仓库身份去重、验证命令和依赖次序。
- 任务计划、执行、验收、停止/恢复、补充、确认完成与受保护的重发；区分排队、运行、用户待决定和内部待核对。
- 独立 Git worktree、macOS 沙箱验证、绑定具体版本的用户合并确认，以及可选 GitHub PR 交付。
- Codex App 原生主控和工作台 MCP；渠道咨询与业务任务分开，主控可向对应项目会话派发需求。
- 钉钉 Stream 与微信文本接入、入站图片/文件；微信任务结果图片/文件具备来源、用户、任务及引用校验。
- SQLite 持久化、消息去重、外发回执核对、任务调查证据、故障监测，以及默认关闭的实验性桌面唤醒。
- 项目知识和 Skill 草稿；启用与交付仍需用户明确操作。

## 安装与运行

准备 macOS、Node.js 24+、npm、Git 及已登录配置的 Codex CLI。原生模式额外需要兼容 Codex/ChatGPT 桌面 App；GitHub PR 模式需要 `gh` 和仓库权限。

```sh
git clone https://github.com/gongxianshengjiadexiaohuihui/personal-ai-workbench.git
cd personal-ai-workbench
git checkout v0.1.0
npm ci
cp .env.example .env
chmod 600 .env
# 将 .env 中的 CODEX_BIN 修改为 command -v codex 的实际路径
npm run build
npm start
```

访问 <http://127.0.0.1:48761>。启动默认不启用渠道或原生主控，需用户自行配置。Codex 沿用本机认证和提供方，不能假定所有执行都使用订阅额度。`.data/` 保存运行数据；服务只用于可信本机环境，不应公开代理。

可选后台常驻：先运行 `npm run launchagent -- print` 核对，再执行 `npm run launchagent -- install`。本次发布没有安装或更改用户现有后台服务。

## 版本来源与部署差异

发布前本地代码已有若干提交，且存在未提交的主控监测、桌面唤醒、消息核对和微信结果附件修复。纯旧提交的对话回归会因预期的 plan 事件不存在而失败；当前工作区测试已适配来源消息走项目会话的路径，并保持无来源消息的计划路径覆盖，18 个脚本通过。

此次首版以通过验证的当前工作区快照为基础，在独立目录创建公开仓库初始提交。没有将旧提交直接打标签，也没有覆盖或提交原工作区的并行改动。公开包去除了内部验收记录、业务截图、运行数据和凭据；泛化了一处 UI 本机路径示例，整理新用户文档并增加统一验证入口。

采集时，当前工作区编译出的 30 个后端文件与运行目录逐字节一致，前端入口及当前引用 JS/CSS 也一致；运行目录另保留 3 个旧资源。公开版本只有上述路径示例带来前端资源差异，后端行为代码没有改变。本次没有部署新版本或重启既有工作台，发布成功不代表本机运行目录已切换到公开仓库。

## 已知问题、未完成能力与边界

- Codex 项目发现依赖内部数据库结构，原生会话与队列依赖实验接口。验证机安装了 Codex CLI `0.171.0-alpha.13.2`，本次未重新验证该版本的真实业务模型链路；其他 App/CLI 版本的兼容性未知。
- 桌面唤醒只尝试满足条件的新消息；导航成功不代表消息被消费或任务成功。旧积压、暂停、未知回执需要核对。自动创建修复会话、自动修复验证和完整归档闭环尚未实现。
- 真实微信/钉钉附件接收、项目会话消费和结果手机收件，本次未做端到端验收。`sent` 仅表示接口接受，不能代替用户实际接收确认。
- GitHub PR、必需 CI 和远端合并业务路径本次未联调；首版仓库及 Release 发布是另外的交付操作，不证明这条业务功能通过。
- 没有复杂项目、长时间运行、App 重启、休眠唤醒和用户并发操作的完整覆盖；不承诺任意任务无人值守完成。
- 凭据文件权限限制为 0600，但未加密存储。服务适用于可信本机单用户，不提供多租户隔离或远程节点。
- 构建有 Zod 的 PURE 注释位置警告；Node SQLite 可能显示实验功能警告。构建完成不表示这些上游接口已稳定。
- 没有通用数据库降级迁移、自动更新、真实费用估算或生产部署支持。回退前停服务并同时备份代码与整个数据目录，不能假定旧版可读取已升级数据。
