# 个人工作主控

此目录保存工作总管职责与明确的项目知识，业务事实以个人工作台数据库为准。

## 接入

1. 在 Codex App 新增项目“个人工作主控”，选择本目录。
2. 在该项目创建总控会话，并在工作台明确选择订阅认证或沿用现有提供方；不要将 API Key 调用描述为订阅调用。
3. 将工作台系统设置显示的 personal_workstation stdio MCP 服务接入本项目。
4. 将 App 项目 ID、总控会话 ID 和本目录填入工作台系统设置，完成核对后启用。身份变化须重新确认。

## 总控与专项会话

稳定职责见 [AGENTS.md](AGENTS.md)，具体工作方法见 [personal-workstation Skill](.agents/skills/personal-workstation/SKILL.md)。总控理解渠道自然语言，普通咨询直接回答，明确需求通过 MCP 创建任务；渠道执行需求按工作台项目关联创建对应的项目会话并交由其直接执行。钉钉来源回合的最终答复自动回传，App 内其他对话不转发。

会话角色及任务归属以工作台绑定记录为准。原生个人记忆辅助理解偏好，数据库与实际证据保持权威。现有提供方配置不因本次改造而改变。
