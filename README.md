# 个人 AI 工作台

面向 **macOS 本机单用户**的个人研发工作台：管理本地项目和任务，使用 Codex 执行研发工作，收集验证证据，并在用户确认后交付。提供 React Web 界面、钉钉和微信接入，以及可选的 Codex App 原生主控。

**v0.1.0 是首个实验性预发布版本。** 它是 Node.js 源码应用，不是独立 macOS App；没有 DMG、PKG、应用签名或公证。实际验证环境为 macOS 15.3.1 / Apple Silicon arm64 / Node.js 24.18.0。Windows、Linux 不在当前支持范围，Intel Mac 与其他 macOS 版本尚未验证。

完整功能、验证和限制见 [v0.1.0 发布说明](docs/releases/v0.1.0.md)。

## 安装与启动

需要 Node.js **24 或更高版本**（实际验证 24.18.0）、npm、Git、`/usr/bin/sandbox-exec`、`/bin/zsh` 和已配置登录的 Codex CLI。任务执行沿用本机 Codex 认证与提供方，可能产生相应费用；启动空工作台不要求配置消息渠道。原生主控额外需要兼容版本的 Codex/ChatGPT 桌面 App。GitHub PR 交付额外需要 `gh`、登录状态和仓库权限。

```sh
git clone https://github.com/gongxianshengjiadexiaohuihui/personal-ai-workbench.git
cd personal-ai-workbench
git checkout v0.1.0
node --version    # 确认当前终端正在使用 Node 24+
npm ci
cp .env.example .env
chmod 600 .env
# 编辑 .env：将 CODEX_BIN 改为 command -v codex 的实际输出
npm run build
npm start
```

打开 <http://127.0.0.1:48761>。服务只绑定本机回环地址，不应代理到公网。首次运行使用 `.data/` 保存数据库和配置；`DATA_DIR` 可以指定独立目录。不要把现有业务数据复制到公开仓库。开发模式分别运行 `npm run dev` 和 `npm run dev:web`，前端开发入口为 <http://127.0.0.1:5178>。

后台运行可先执行 `npm run launchagent -- print` 检查路径，再按需执行 `npm run launchagent -- install`；卸载使用 `npm run launchagent -- uninstall`。安装会使用当前 Node 和项目绝对路径，不能随意移动或删除该目录。首发验证只检查了 plist 生成及语法，没有安装新的后台服务。休眠和关机期间不保证执行与通知。

## 使用范围

- **项目**：注册本地 Git 仓库，或只读发现 Codex 项目再确认导入；支持多个仓库、验证命令及依赖。非 Git 目录初始化需要显式确认。
- **任务**：查看任务阶段、执行记录、最终结果和证据，支持补充、停止、恢复、确认完成和受保护的重发。排队不代表已执行，确认完成不代替合并确认。
- **交付**：执行组使用独立 Git worktree，验证命令在 macOS 沙箱内运行。用户核对具体版本后才合并；工作区不干净、基线变化或验证不满足时会阻止交付。GitHub PR 为可选路径，首发未做真实远端 PR/CI/合并联调。
- **原生主控**：默认关闭；通过设置绑定 App 项目和主控会话，再接入工作台 stdio MCP。配置方法见 [主控模板](docs/controller/README.md)。渠道模式由主控把明确需求派发给项目会话，咨询不必创建任务。
- **消息渠道**：可配置钉钉 Stream 或微信登录并绑定操作者。支持文本和入站图片/文件；微信任务结果图片/文件需满足来源消息、任务、用户及文件引用校验后发送。详见 [钉钉配置](docs/dingtalk-setup.md)。
- **运行诊断**：消息和外发回执持久化，未知回执保留待核对，不自动盲重发。实验性桌面唤醒默认关闭，启用后只处理满足条件的新消息，不是完整的自动故障修复。
- **知识与界面**：项目说明、Skill 草稿与用户启用；任务筛选搜索、分页、证据审阅、弹窗未保存提醒及窄屏导航。

## 验证

在 macOS 上运行以下验证。除明确列出的真实探针外，它们使用隔离数据目录、夹具仓库或模拟渠道，不向真实微信/钉钉发送消息。

```sh
npm run verify:release
```

该命令执行类型检查、前后端构建和 18 个验证脚本，覆盖真实 SQLite/Git/沙箱、项目导入、任务生命周期、原生协议、模拟渠道及 UI 数据处理。**脚本通过不代表真实 AI 效果、手机收件或无人值守业务验收通过。** `probe:*` 是独立诊断工具，不属于首发回归；其中部分会调用真实模型或重启桌面 App，不要把它们当成无副作用检查。

## 数据、安全与限制

服务用于自己信任的本机项目，不是多租户平台。SQLite 是任务和授权的事实源；API 写操作检查工作台令牌及 Host/Origin。渠道凭据保存在本机文件，权限为 0600，**没有进行磁盘内容加密**。Skill 生成不等于启用，模型验收不等于用户批准。

Codex 项目发现和原生队列依赖内部数据库/实验接口，跨版本兼容不保证。自动建立修复会话、自动修复验证及完整归档闭环尚未完成。真实渠道附件的手机接收、复杂项目、长时间运行、App 重启/并发操作仍需验证。当前无真实费用估算、远程执行节点或生产服务部署承诺。

升级或回退前先停止对应数据目录的服务，备份整个数据目录、配置及当前代码；保留旧版工作目录。数据库升级会生成部分一致性备份，但本版不提供通用降级迁移，不能将旧代码直接连接到已迁移的数据并假定兼容。

`src/` 为服务端，`web/` 为 React 前端，`scripts/` 为验证及诊断脚本，`docs/` 为配置与发布说明。发布流程见 [RELEASING.md](RELEASING.md)。仓库尚未声明开源许可证；公开可见不等于已授予任意使用、修改和再分发许可。
